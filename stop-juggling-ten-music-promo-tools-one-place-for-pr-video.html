What "PR overload" looks like in practice

The video stays high level, so here is what the problem usually looks like on an artist's desk:

  • Contacts live in three places. A spreadsheet from last year, bookmarks, and a few names saved in a social app.
  • Nobody knows who was pitched. The same writer gets the same song twice, or a promising reply sits unanswered for a week.
  • The pitch changes every time. Each message is rewritten from scratch, so the story of the release drifts.
  • Follow-ups slip. Without one list of who is waiting on what, the second message never goes out.

A ten-minute audit of your own setup

  1. Count the tools. List everything you touched during your last release campaign: apps, sheets, inboxes, docs.
  2. Find the single source of truth. Where is the definitive list of who you contacted and what they said? If the answer is "several places", that's the leak.
  3. Write the story once. Keep one short release description and one artist bio that every pitch starts from.
  4. Track replies in one place. Every response, including "not for us", goes on the same record so the next release starts warmer.
  5. Cut what you don't use. If a tool only duplicates another, drop it before the next campaign starts.
